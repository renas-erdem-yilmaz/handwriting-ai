# Handwriting AI — local desktop application (Step 10)

From the project root, in PowerShell:

```powershell
.\.reforge\Scripts\python.exe -m handwriting_app
```

The existing Python 3.11 environment and local model caches are used. PDF additions
are `reportlab==5.0.1` and `pypdf==6.20.0`, already installed for this implementation.
For another setup: `python -m pip install -r handwriting_app/requirements.txt` within
the working inference environment. Tkinter/Pillow and model dependencies are reused.
No network access, paid API, training, or symbol collection is needed to use the app.

## Use

1. Paste notes or load a UTF-8 `.txt` file. Blank lines separate paragraphs;
   single newlines within paragraphs wrap naturally. Start a heading with `# `.
2. Select A4/Letter, blank/lined paper, individual margins, line spacing, writing
   x-height, word spacing and paragraph gap. Default settings retain conservative
   ±2.5% size variation and the existing aspect-preserving ink normalization.
3. Choose pretrained (default) or the existing 30-update pilot adapter. The adapter
   is available only if its checkpoint exists; strict checkpoint validation remains
   in `page_engine.model`. No improvement from that adapter is assumed.
4. Generate. Input validation, checkpoint hashing, cached word inference, composition
   and export run in background workers. Progress counts prepared word occurrences;
   each can require 1–3 candidates. First uncached words also load the model. Auto
   device uses CUDA where available; CPU is supported but substantially slower.
5. Inspect **every** page with Previous/Next. Review spelling and malformed letters.
   Fit shows the whole page; 75–150% zoom and scrollbars allow closer inspection.
   The saved PNGs retain full resolution.
6. Export to a new PDF filename. Pages are embedded losslessly in preview order with
   exact A4/Letter physical dimensions. The fallback footer is part of the preview
   and PDF. Existing PDFs are never overwritten. Changing notes/settings disables
   export until a new preview is generated, preventing stale-document export.

Cancel stops between word calls, not inside a CUDA/model operation. Completed word
candidates stay cached for retries. Closing during a job requests cancellation;
wait for completion/cancellation, then close again. There is a single model worker:
Reforge temporarily changes global RNG state and working directory, so unsafe
parallel calls and unverified batching are deliberately avoided. The model stays
loaded between compatible jobs; caches and prior candidate selections are reused.

Every run gets a unique directory under the configured preview folder containing
the original input, settings, document, page PNGs, manifest and compatible candidate
review session. Failed runs retain a traceback log; no partial preview is published
as successful. Output destinations inside protected dataset/model/source directories
are rejected. Original data, adapters, pretrained weights and previous outputs are
preserved. New outputs are covered by the project's existing `.gitignore`.

## Math and supported input

Use `$...$` for inline math. An entire paragraph `$F = ma$` or `$$F = ma$$` becomes
a displayed equation. Examples: `$a = F/m$`, `$v = v_0 + at$`, `$x = 1/2 at^2$`,
`$θ = α + β$`, `$v^2 = v_0^2 + 2ax$`. Use braces for compound scripts and grouped
denominators: `$x^{12}$`, `$F/(ma)$`. The existing restricted syntax and legacy
Mathtext fallback are unchanged; see `page_engine/math_symbols/README.md`.
When **all** required symbols have reviewed crops, the renderer uses them. Missing
or unapproved symbols trigger a labeled whole-equation standard-font fallback,
with missing inventory in the page manifest and GUI. No symbol is auto-approved.

Prose follows the existing model's English-word vocabulary: ASCII letters, internal
apostrophes/hyphens and one trailing `.,;:!?`. Put numbers/non-English symbols in
math markup. Unsupported prose or malformed markup fails before inference with
an explanation; it is never dropped or silently converted. Notes up to 100,000
characters are accepted; large documents can take hours depending on hardware and
cache coverage. Equations remain indivisible; very wide tokens require smaller
writing scale or a wider usable page. Bounding-box checks catch clipping/overlap,
but cannot establish spelling or correct glyph identities generated by DiffusionPen.

## Existing word and symbol review tools

Each run's `session.json` works with the existing reviewer:

```powershell
.\.reforge\Scripts\python.exe -m page_engine.quality review --session outputs/app_runs/<run_directory>/session.json
.\.reforge\Scripts\python.exe -m page_engine.math_symbols collect
```

Finish/cancel generation before running other inference/review-regeneration tools.
After selecting candidates or approving symbols, regenerate with the same input,
seed, sampling and model to reuse the decisions. Current previews/PDFs are immutable
snapshots and do not update automatically. No human approvals are fabricated.

## Reproducible headless generation and tests

```powershell
.\.reforge\Scripts\python.exe -m handwriting_app --text-file handwriting_app/example.txt --output outputs/app_runs --pdf outputs/app_runs/my_notes.pdf --page A4 --paper lined
.\.reforge\Scripts\python.exe -m unittest handwriting_app.tests page_engine.tests page_engine.quality_tests page_engine.scale_tests page_engine.math_symbols.tests
```

Use a fresh PDF filename. The CLI and GUI call the same service. Tests use explicitly
synthetic temporary model fixtures to verify input preservation, long multi-page
pagination, cancellation/recovery, Tk event-loop responsiveness, math fallback,
PDF physical sizes/page counts, and byte-for-byte embedded preview pixels.
Actual pretrained-model smoke tests and sample PDFs are described in
`outputs/app_tests/integration_report.json` when generated.

Remaining limitations are inherited from the model: inconsistent letter shapes,
misspelled/merged letters, and imperfect resemblance to the writer. Lossless export
preserves these pixels; it does not improve handwriting quality. The symbol library
can be populated later without blocking ordinary notes or mathematical font fallback.
